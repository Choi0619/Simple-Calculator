# Simple-Calculator

## Description
This is a **simple calculator** application built using **Python**. It provides basic arithmetic operations such as addition, subtraction, multiplication, division, and more. The calculator is designed with a graphical user interface (GUI) to make it user-friendly and visually appealing.

## Features:
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Square (^2)
- Percentage (%)
- Clear (C)
- Delete (<)
- Equals (=)
